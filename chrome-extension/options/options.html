Use your own API key to access language models. Your key is stored locally in this browser and sent through your configured backend to your chosen model provider.

1. Server

Default: http://localhost:5174. For a hosted Open-PaperKid backend, enter its full HTTPS URL. Deployment guide: DEPLOY.md

2. Model provider

For Ollama or a custom OpenAI-compatible endpoint, including Token Plan. This is separate from the backend API URL.

3. API key

The backend forwards your key to the selected provider; it does not persist the key.

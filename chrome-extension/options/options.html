Open-PaperKid 设置BYOK

Open-PaperKid 默认通过你自己的 API Key 调用大模型。Key 只保存在本浏览器本地存储,不发送到任何第三方服务器,也不写日志。

1. 服务器地址

本地默认:http://localhost:5174。如果你部署到了云端(参见 DEPLOY.md),填完整的 https URL。

2. 模型 Provider

Ollama 或自定义 OpenAI 兼容代理时填写,其余情况留空。

3. API Key

本扩展只把 Key 发给你配置的 Open-PaperKid 后端,绝不发送到任何第三方(包括本项目作者)。
